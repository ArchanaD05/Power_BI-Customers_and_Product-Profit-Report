# 📊 Customers & Products Profits Dashboard (Power BI)

## 📌 Overview  
This project showcases an **interactive Customers & Products Profits Dashboard** built using **Power BI**. It provides deep insights into **product performance, customer purchasing behavior, production costs, and regional sales distribution**.

The dashboard helps stakeholders understand **which products and customers drive revenue and profitability**, enabling better decision-making.

---

## 🚀 Key Features  

### 📦 Product Performance Analysis
- Units sold by product name  
- Comparison of product demand across categories  
- Identification of top-performing products  

### 💰 Cost & Profit Insights
- Comparison between **product price vs production cost**  
- Helps identify high-margin vs low-margin products  

### 📅 Time-Based Trends
- Product purchases analyzed over time  
- Monthly trend analysis for different products  

### 👥 Customer Insights
- Customer-wise purchase contribution  
- Breakdown of units sold by each customer  
- Top customers driving sales volume  

### 🌍 Regional Analysis
- State-wise distribution of total purchases  
- Identifies high-performing geographic regions  

### 📊 Key Metrics (KPIs)
- Total Purchases Count: **50**  
- Minimum Purchase Value: **9**  
- Total Units Purchased: **22K**

## 📊 Dashboard Components  

| Section                          | Description                                              |
|----------------------------------|----------------------------------------------------------|
| Units Sold by Product            | Bar chart showing product-wise sales volume              |
| Production Cost vs Price         | Combo chart comparing cost and selling price             |
| Products Purchased by Date       | Line chart showing trends over time                      |
| Customer Purchase Breakdown      | Stacked bar showing customer contribution                |
| Purchases by State               | Donut chart showing regional distribution                |
| Product Price vs Cost Scatter    | Scatter plot for margin analysis                         |
| Customer Table                   | Tabular view of top customers and units sold             |
| KPI Cards                        | Summary metrics at the top                               |
